# Shanghai Box — сайт

Статичный сайт: товары из Китая под заказ с доставкой до пункта СДЭК. Заказы — в Telegram-боте [@shanghaibox_bot](https://t.me/shanghaibox_bot).

- `site/` — страницы, шрифты и QR-коды; публикуется на GitHub Pages workflow `.github/workflows/pages.yml`.
- Сайт не собирает персональные данные, не ставит cookies и не обращается к сторонним сервисам.
